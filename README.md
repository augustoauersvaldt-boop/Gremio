# Grêmio - Projeto front-end

Este projeto vem a entender o bom uso e css sobre as paginas e bom uso de programação

## Oque foi feito

- Criação de estrutura de HTML em Pagina
- Organização de conteúdo em seções
- `herdar`,`nav`,`main`,`section`,`article` e `table`
- colocamos banner
- fizemos estilização de css
- definimos cores, fontes, espaçamentos e layout visual

## Estrutura do projeto

- `index.html` - estrutura da página
- `style.css` - estilo e layout do site
- `imagem/` - imagens usadas do projeto
